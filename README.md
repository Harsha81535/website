# Harshana — Portfolio Website

Responsive editorial-style static portfolio intended for free GitHub Pages hosting.

## Before publishing
1. Open `index.html` in a text editor.
2. Replace `YOUR_EMAIL` in the contact button with your professional email.
3. Check that all project links work.
4. Project 2 currently links to its GitHub repository only because its live-app URL has not been confirmed. Add that URL once confirmed.

## Publish free with GitHub Pages
1. Sign in to GitHub.
2. Create a **public** repository named exactly `Harsha81535.github.io` (provided your GitHub username remains `Harsha81535`).
3. Upload `index.html` and `README.md` to the repository root.
4. Open repository **Settings → Pages**.
5. Under build/deployment, select **Deploy from a branch**, choose **main** and **/(root)**, then save.
6. Wait for the published URL shown on the Pages settings screen.
7. Open the site on desktop and mobile and test every link.

A custom domain is optional; do not buy one for the first version.
